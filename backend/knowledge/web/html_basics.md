# Web Development Expert Knowledge - HTML

## What is HTML?
HTML (HyperText Markup Language) is the standard markup language for creating web pages. It describes the structure of a web page semantically.

## Basic Structure
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Page</title>
</head>
<body>
    <h1>Welcome to Sarala's Web Lab</h1>
    <p>This is a simple paragraph.</p>
</body>
</html>
```

## Common Elements
- `<h1>` to `<h6>`: Headings.
- `<p>`: Paragraph.
- `<a>`: Anchor (links).
- `<img>`: Image.
- `<div>`: Division or section.
