# Programming Expert Knowledge - Python

## What is Python?
Python is a high-level, interpreted programming language known for its readability and versatility. It was created by Guido van Rossum and first released in 1991.

## Key Features
- **Easy to Learn:** Clear syntax and readability.
- **Interpreted:** Executed line-by-line, which makes debugging easier.
- **Large Standar Library:** Extensive tools for everything from web dev to data science.
- **Dynamic Typing:** No need to declare variable types.

## Basic Syntax Example
```python
# Variables and Printing
name = "Sarla AI"
print(f"Hello, {name}!")

# Loops
for i in range(5):
    print(f"Iteration {i}")

# Functions
def greet(user):
    return f"Namaste, {user}!"
```
